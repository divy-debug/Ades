AUTOMATED DEBATE EVALUATION SYSTEM (ADES)

This is a sophisticated agentic framework using multi-agent system logic that simulates professional debates between AI Agents which is then further evaluated by an unbiased Judge AI Agent.

The system uses **AGNO** library to create 3 different agents namely: PRO,CON and JUDGE.

Tech Stack
- Agno Library
- Local API: Ollama (Llama 3.2).
-Cloud API: Groq (Llama 3.3 70B).
-Environment: uv (python)
